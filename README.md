### What it does
Petflix Studio automates viral pet content for creators with low bandwidth:
- **Generator Tab:** Photo captions (3 variations), Text posts, Story polls (≤15 words), 65s Reel/Snap scripts (hook + 3 beats)
- **Analytics Tab:** WAT (Lagos) posting schedule optimization for Facebook monetization & Snapchat 3k hours
- **Neural Image Lab:** Photorealistic thumbnail generation (1:1, 9:16) with prompt tricks to avoid AI artifacts

### Tech Stack
- Frontend: Single-file HTML/CSS/JS PWA
- AI: Gemini 3 Flash (Structured JSON outputs), migrating to Meta Llama 3 for hackathon
- Prompt Engineering: Brand voice (funny, chaotic, warm, Nigerian), JSON schemas for photo_captions[3], text_post, story_text, reel_hook, reel_script[3]
- Offline-first templates for Lagos low-network

### Why it matters
Solves real monetization for 89k+ creators — comment-bait > likes, Pidgin + English localization, works on 3G.
